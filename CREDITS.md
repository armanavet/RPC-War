# Credits

## Artwork

The unit and terrain artwork in the four wargames — Salient, Tideline,
Breakthrough and Barbican — comes from **[Game Icons](https://game-icons.net)**,
drawn by **Lorc, Delapouite and contributors**, and is used under the
[Creative Commons Attribution 3.0 licence](https://creativecommons.org/licenses/by/3.0/).

The icons are used unmodified as path data. What differs between the four games
is entirely in how that artwork is presented — pre-rendered enamel counters,
moulded tokens, flat poster silhouettes and heraldic shields — not in the
drawings themselves.

The path data is vendored into
[`js/games/_shared/icons.js`](js/games/_shared/icons.js), generated by
[`tools/build-art.mjs`](tools/build-art.mjs) from the npm package
`@iconify-json/game-icons`. The site itself has no runtime dependency on it.

Icons used, by their names in the set:

| game | units |
|---|---|
| Salient | medal · walkie-talkie · brodie-helmet · battle-tank · field-gun · trench-spade · jeep · cargo-crate |
| Tideline | crown · bordered-shield · mounted-knight · catapult · spears |
| Breakthrough | binoculars · trench-assault · great-war-tank · mortar · walking-scout · rifle |
| Barbican | knight-banner · spears · crossed-swords · siege-ram · trebuchet · ladder · war-pick · crown · archer · bordered-shield · mounted-knight |
| ground | forest · hills · village · swamp · stone-wall · watchtower · gate · broken-wall · castle · stone-bridge |

## Everything else

The two original games (RPS Chess and Anvil) use artwork generated for this
project. Type is whatever the reader's operating system already provides — no
web fonts are loaded, from anywhere.
